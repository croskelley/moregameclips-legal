Privacy Policy

moregameclips · effective October 24, 2026

Whose data

moregameclips is a private tool used only by its operator, on the operator's own accounts. It has no other users and collects no data about anyone else.

What it reads

With the operator's authorization, moregameclips reads, through each platform's official API:

  • TikTok: the operator's basic profile (display name and open ID) and the list of the operator's own public videos with their view counts.
  • YouTube: public view counts of the operator's own videos.
  • Instagram: view counts of the operator's own posts, if connected.

How it is used and stored

The data is used only to show the operator how their clips are performing. It is stored on the operator's own computer, is not uploaded to any server run by moregameclips, and is never sold, shared or used for advertising. Access tokens are kept on the same computer and used only to make the reads above.

Removing access and data

Access can be revoked at any time in the platform's settings (for TikTok: Settings and privacy, Security, Manage app permissions). Ask at the address below and the stored data will be deleted.

Changes

This policy may change; the effective date above shows the latest version.
